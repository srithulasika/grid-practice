# CSS Grid & Layout Practice

A collection of HTML and CSS practice exercises completed while learning CSS Grid, Flexbox, responsive layouts, media queries, and Git version control.

## Levels Covered

### Level 1 – Basic
- CSS Grid with equal columns and rows
- Grid gaps and media queries
- Pixel to rem conversion
- Viewport meta tag
- Basic Git commands

### Level 2 – Intermediate
- Two-column layouts and card galleries
- Responsive layouts using media queries
- `auto-fit()` and `minmax()`
- Relative units: `rem`, `em`, `vh`, and `vw`
- Responsive navbar using Flexbox
- Git branching and README creation

### Level 3 – Advanced
- Page layouts using `grid-template-areas`
- Magazine front page using CSS Grid
- Photo wall using `grid-auto-flow: dense`
- Nested layouts using Grid and Flexbox
- Responsive navbar
- Git commit history, pull, push, and merge
- Handling rejected Git pushes

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Git
- GitHub

## What I Learned

- Creating responsive layouts using CSS Grid and Flexbox
- Working with relative CSS units
- Using media queries for different screen sizes
- Managing projects with Git and GitHub
- Creating branches, commits, and resolving rejected pushes
